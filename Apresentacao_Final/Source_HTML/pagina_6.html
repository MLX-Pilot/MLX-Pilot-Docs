Arquitetura Modular

Sistema plugável onde cada componente (UI, Core, Providers) opera de forma desacoplada, facilitando manutenção e upgrades.

trait Provider { fn infer(&self, prompt: str); }

Multi-Provider

Camada de abstração unificada que permite alternar entre backends (MLX, Llama, Ollama) em tempo de execução sem reiniciar.

let backend = ProviderFactory::create(config.type);

Streaming Real-time

Implementação eficiente de Server-Sent Events (SSE) para entrega de tokens com latência mínima na interface do usuário.

response.stream().map(|chunk| Event::default().data(chunk))

Catálogo Hugging Face

Integração nativa com a API do Hugging Face para busca, filtragem e download automatizado de modelos GGUF e MLX diretamente pela interface.
