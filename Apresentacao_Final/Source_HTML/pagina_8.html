Academic Goals

Objetivo Acadêmico

RESEARCH_FOCUS // EXPERIMENTATION // BENCHMARK

01

Arquitetura Modular

Estudo aprofundado sobre desacoplamento de sistemas, separando interface (Tauri) do controle lógico (Rust) e inferência.

02

Local vs Remoto

Análise comparativa crítica entre execução local (privacidade, latência zero) e nuvem (custo, escalabilidade).

03

Benchmark

Coleta sistemática de métricas de performance: Tokens por segundo (TPS), Tempo para o primeiro token (TTFT) e uso de memória.

04

Stress Test GPU

Avaliação de limites de hardware com modelos massivos (7B+), monitorando temperatura, consumo energético e gargalos de VRAM.

05

Base de Pesquisa

Criação de uma plataforma estável e documentada para servir como fundação para futuros Trabalhos de Conclusão de Curso (TCC).
