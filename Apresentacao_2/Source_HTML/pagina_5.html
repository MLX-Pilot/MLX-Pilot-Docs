System Flow

Fluxo de Execução

CHAT // AGENTE // WORKFLOWS

Toda requisição entra por um de três caminhos, cada um com sua rota no daemon, e todos terminam na mesma base compartilhada.

Chat/chat/stream
Resposta token a token via SSE, direto do runner ou provedor, sem ferramentas.
Agente/agent/run
Runtime clássico ou OODA: monta o prompt com orçamento de tokens, o modelo decide entre texto e ferramenta, a política permite, pergunta ou nega, e a ferramenta roda no sandbox, em ciclo.
Workflows/flows/*
Valida o grafo (DAG sem ciclos) e executa em paralelo as camadas de nós independentes: agent, tool, MCP ou HTTP. O nó agent reaproveita o runtime do agente.
Base compartilhada
Modelos locais ou em nuvem, ferramentas, servidores MCP e o estado em disco: sessões, memória e execuções.
